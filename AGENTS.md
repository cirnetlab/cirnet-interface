# Interface repository work

- Write each AI task's plan only in `.superpowers/plans/` and its matching spec, acceptance criteria and checklist only in `.superpowers/specs/`.
- Use `- [ ]` for open items and `- [x]` after verified completion. Update [English](docs/en/index.md), [Vietnamese](docs/vi/index.md) and the [changelog](docs/changelogs/README.md) after verification.
- Verify against reviewed Contracts artifacts and the [verification guide](docs/en/contributing/verification.md). Interface owns browser behavior. Canonical schema and catalog writes belong to Contracts. Use packaged inputs and preserve unavailable capability declarations.
- Preserve source assets, original artwork and provenance, historical evidence and test baselines.
- Use the shared allocator for raw and visual output outside all checkouts, worktrees and Git administration directories from the first write. Inspect it and clean only the owned session. Keep Markdown evidence in source.
- Review Git diff, status and ignored outputs. Stage, commit, merge, push or deploy only on request.
