# CIRNET Interface

[English documentation](docs/en/index.md) · [Tài liệu tiếng Việt](docs/vi/index.md) · [Changelogs](docs/changelogs/README.md)

CIRNET Interface is the Vue and Three.js browser workbench for circuit design, private projects and experiments with CIRNET lab services.

<a id="run-and-verify"></a>

- [Get started](docs/en/guides/getting-started.md) with the reviewed Contracts inputs and Vite.
- [Use the workbench](docs/en/guides/workbench.md) to edit, wire and run a circuit.
- [Read the architecture](docs/en/architecture/workbench.md) for the browser, graph and service boundaries.
- [Verify](docs/en/contributing/verification.md) or [build and deploy](docs/en/operations/deployment.md) the Interface product.

The source identifies as `@cirnet/web` 0.1.4. CIRNET Remote owns the [canonical Lab-First architecture](https://github.com/cirnetlab/cirnet-remote/blob/13a35145b6d15644c7be10d95a5410bf69e11867/docs/ARCHITECTURE.md) and selects published Interface artifacts in the [system 0.1.4 release lock](https://github.com/cirnetlab/cirnet-remote/blob/38aea6120920f48cea817827ac2277cce4bef25e/integration/release-set.json).
